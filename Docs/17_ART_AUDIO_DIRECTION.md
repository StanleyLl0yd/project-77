# Project 77 — Art & Audio Direction

## 1. Visual thesis

Главный визуальный контраст:

**тёплый, живой, персональный остров** против **холодной, точной, неизвестной древней технологии**.

По мере выхода в космос эти языки постепенно смешиваются.

## 2. Camera / presentation

Рабочий вектор: stylized 2.5D/isometric presentation с крупными, легко читаемыми формами.

Orientation остаётся OPEN до UX prototype. Важнее:

- one-hand comfort;
- readable island;
- core puzzle screen clarity;
- store screenshot appeal.

## 3. Island palette language

Не фиксируя конкретные RGB:

- тёплая растительность;
- дерево/камень/ткань;
- мягкий естественный свет;
- следы старой научной инфраструктуры;
- уют усиливается по мере восстановления.

## 4. Ancient technology language

- чистая геометрия;
- светящиеся линии;
- непривычные пропорции;
- отсутствие очевидных кнопок/винтов/человеческой инженерной логики;
- глифы, которые позже повторяются на других планетах.

## 5. Robot 77 silhouette

Требования:

- узнаваем в 48–64 px;
- простой силуэт;
- крупная «лицевая» область/глаза для эмоций;
- 2–3 поверхности для skins;
- аксессуары не ломают силуэт;
- цифра/маркировка 77 читается, но не обязана быть огромной.

77 должен работать как app icon candidate и merchandise-friendly mascot.

## 6. Character style

Не стремиться к реалистичным человеческим лицам. Лучше стилизованные персонажи с ясной позой/ролью, чтобы снизить production cost и uncanny risk.

## 7. Environment storytelling

Каждая зона должна отвечать на вопрос «что здесь произошло?» визуально:

- незаконченный ремонт;
- закрытые контейнеры;
- странно вырезанный участок скалы;
- кабель, уходящий не туда;
- человеческое оборудование рядом с явно нечеловеческим материалом.

## 8. Planet differentiation

Каждый мир получает один dominant visual rule:

- Borealis — лёд + внутреннее свечение;
- Viridia — биолюминесцентная органика;
- Nereida — вода/отражения/вертикальные острова;
- desert world — ветер, песок, монолитные руины;
- Mechanis — бесконечная машинная логика.

Не делать каждый мир набором всех эффектов сразу.

## 9. UI

- UI служит миру, а не закрывает его;
- минимум валют в top bar;
- clear primary CTA;
- premium surfaces не должны быть самыми яркими элементами каждого экрана;
- 77 может быть contextual helper, но не постоянная talking head overlay.

## 10. Audio identity

### Island

- ветер;
- море;
- птицы;
- мягкие механические звуки восстановления;
- спокойная melodic texture.

### Mystery

- редкие низкие сигналы;
- далёкие pulses;
- sonic motif 77;
- почти неслышимый motif сети.

### Ancient tech

Звук должен быть не «лазер sci-fi», а точный, музыкальный, необычный.

### Reveal

Крупные открытия получают узнаваемую вариацию одной музыкальной темы. Так игрок подсознательно связывает остров, 77 и сеть миров.

## 11. Dynamic music

Музыка может собираться слоями:

- base island ambience;
- restored layer;
- mystery layer;
- anomaly layer.

Это дешевле бесконечного количества треков и создаёт ощущение живого мира.

## 12. Cosmetic audio

Осторожно монетизировать звуки. Визуальные cosmetics безопаснее. Не продавать раздражающие громкие effects, которые слышат другие игроки без контроля.
