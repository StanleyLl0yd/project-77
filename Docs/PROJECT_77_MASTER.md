## Locked current baseline

- Internal codename: **Project 77**; commercial title not yet cleared.
- Companion/mascot: robot **77**.
- Macro arc: abandoned island → underground complex → ancient vessel → space → other planets → world network.
- Main story remains free.
- Monetization direction: Season Pass, optional subscription, cosmetics, convenience IAP, rewarded ads.
- Unity 6.3 LTS + C# + URP.
- Android-first, cross-platform architecture.
- Prototype before production-art/store/backend expansion.
- No free-form chat/UGC at launch.
- No paid loot-box launch dependency.

## Prototype 0.1 rule

Until P0 + P1 return **CONTINUE**, do not prioritize production art, a large backend, IAP/store, ads, subscription, Season Pass, planets, ship systems, or mass content production.

The decisive product question is not whether the build runs. It is whether an external player understands `Puzzle → Reward → Island Change/Discovery` and **voluntarily wants to continue**.
