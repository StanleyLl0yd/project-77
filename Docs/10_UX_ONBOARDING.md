# Project 77 — UX & Onboarding

## Status / current-phase note

The detailed "first 60 seconds" below is a **future FTUE hypothesis**, not the active Prototype 0.1 sequence. During P0/P1, `28_PROTOTYPE_01_SPEC.md` is authoritative and currently tests `puzzle -> reward -> generator repair -> visible island change/area unlock -> discover 77`. Final production timing of the 77 reveal is intentionally not locked until playtest evidence exists.

## Goal

Игрок должен начать играть почти сразу. Мир и mystery объясняются через действие.

# First 60 seconds

### 0–10 sec

Короткий establishing shot острова и повреждённого причала. Игрок получает контроль.

### 10–25 sec

Первый micro-puzzle буквально из одного жеста.

Никаких меню, валют и магазина.

### 25–40 sec

Результат puzzle физически меняет мир: включается питание/опускается мост/освобождается путь.

### 40–60 sec

Из завала/контейнера появляется 77. Короткая реакция. Новый вопрос.

Игрок должен уже получить три reward types:

- solved;
- world changed;
- character discovered.

# First 10 minutes

1. 3–5 простых puzzle levels.
2. Восстановление маленького лагеря.
3. Имя/знакомство с 77.
4. Выбор одного cosmetic варианта — бесплатный.
5. Короткий exploration beat.
6. Первая странность: 77 знает то, чего знать не должен.
7. Cliffhanger перед естественным окончанием первой сессии.

Не показывать:

- 5 валют;
- Season Pass;
- subscription;
- сложные collections;
- social leaderboard;
- космос.

# First day

Игрок должен:

- открыть 2–3 landmark;
- получить первую коллекцию;
- отправить первую простую экспедицию;
- найти странный предмет;
- увидеть ограниченное Daily UI;
- понять, что остров можно персонализировать.

# First monetization touch

Сначала показать ценность персонализации бесплатно.

После того как игрок получил/выбрал несколько объектов, магазин может мягко появиться как источник дополнительных вариантов.

Starter Pack — только после сформированной ценности, не поверх первой эмоциональной сцены.

# First week

Цели:

- сформировать привычку;
- дать 2–3 вопроса mystery;
- открыть пещеру или путь к ней;
- познакомить с event/season;
- дать редкий предмет, который физически остаётся на острове.

# First month

Игрок должен чувствовать, что прошёл значимый путь, а не просто 300 уровней.

Желаемые milestones:

- остров заметно преобразился;
- 77 восстановил часть памяти/функций;
- несколько персонажей стали «своими»;
- открыт подземный слой;
- появилось понимание, что история существенно больше стартовой premise.

Точный момент ship reveal определяется реальной progression telemetry.

# UI principles

- один primary action на экране;
- минимальное количество badges/red dots;
- ясная иерархия;
- premium UI не должен выглядеть громче story UI;
- игрок всегда понимает, что получил и почему;
- back navigation предсказуемая;
- avoid modal stack hell.

# Accessibility

- scalable text;
- no color-only puzzle information;
- haptic toggle;
- reduced motion;
- subtitles/text log для narrative;
- left/right-hand friendly gestures;
- contrast modes where practical.
