# Project 77 — Game Design Document

Версия: **0.5 / Prototype Phase**

## Implementation baseline

- Unity 6.3 LTS / C# / URP.
- Android-first, cross-platform architecture.
- Первый milestone — **Project 77 Prototype 0.1**: P0 compares three greybox core variants, then the winner is integrated into a 10–20-level `puzzle -> reward -> island change/discovery` path ending with generator repair and 77 discovery.
- Production art, monetization и большой backend не являются prerequisite для первого прототипа.
- Pre-production завершён; активный implementation contract — `28_PROTOTYPE_01_SPEC.md`.
- До CONTINUE по P0/P1 действует prototype scope freeze и правило data-over-speculation.
- Operational protocol: `29_PROTOTYPE_PLAYTEST_PROTOCOL.md`; telemetry contract: `30_PROTOTYPE_ANALYTICS_CONTRACT.md`; engineering conventions/backlog: `31_ENGINEERING_CONVENTIONS.md` / `32_PROTOTYPE_IMPLEMENTATION_BACKLOG.md`.

## 1. Game overview

Project 77 — сюжетная mobile-first F2P puzzle-adventure игра с базой, коллекционированием и LiveOps.

Игрок прибывает на давно заброшенный остров, чтобы восстановить старый исследовательский объект. Робот **77** должен стать ранним компаньоном, но точный production FTUE timing его появления не LOCKED. В активном Prototype 0.1 специально тестируется последовательность `puzzle -> reward -> generator repair -> visible change/area unlock -> discover 77`; после P1 финальный ранний pacing можно скорректировать по данным. По мере восстановления территории обнаруживаются несоответствия: неизвестный металл, странные сигналы, запечатанные помещения и следы исчезнувшей экспедиции.

Под островом находится старый исследовательский комплекс, а ещё глубже — аппарат внеземного происхождения. После его восстановления игра открывает следующий масштаб: орбиту, чужие планеты и сеть древних миров.

## 2. Player verbs

Основные действия игрока:

- решить;
- получить;
- восстановить;
- открыть;
- исследовать;
- выбрать;
- украсить;
- собрать;
- отправить экспедицию;
- вернуться;
- показать;
- разгадать.

Игра не строится вокруг боёвки.

## 3. Core loops

### 3.1 Micro loop — 30–90 секунд

1. Игрок запускает короткую головоломку.
2. Решает задачу одним пальцем.
3. Получает базовую награду.
4. При желании забирает бонус/дополнительную награду.

### 3.2 Session loop — 3–10 минут

1. Несколько головоломок.
2. Получение ресурсов.
3. Одно заметное действие в мире: починка, расчистка, декор, исследование, диалог.
4. Маленький narrative beat или новая цель.
5. Подготовка следующего действия/экспедиции.

### 3.3 Daily loop

- ежедневный подарок;
- 3–5 daily goals;
- прогресс основной истории;
- экспедиция;
- событие/коллекция;
- визит к другу или общественное событие по желанию.

### 3.4 Weekly loop

- недельная цепочка задач;
- один заметный milestone базы;
- один редкий collectible;
- social/community progress;
- развитие сезонной шкалы.

### 3.5 Seasonal loop

35–42 дня как базовая гипотеза.

- новая тематическая коллекция;
- мини-сюжет;
- бесплатная и premium ветки наград;
- 1–2 уникальных островных объекта;
- редкая косметика 77/корабля/персонажей;
- community finale.

### 3.6 Long-term loop

Остров → подземный комплекс → корабль → первая планета → несколько планет → сеть врат → неизвестные создатели сети.

## 4. Metagame: Island Home

Остров — постоянная база.

Он состоит из зон, которые открываются постепенно:

1. Pier / берег.
2. Camp / старый лагерь.
3. Lighthouse ridge / маяк.
4. Jungle sector / заросли.
5. Research station / станция.
6. Cave system / пещеры.
7. Underground complex / подземный объект.
8. Launch site / скрытый стартовый комплекс.

После выхода в космос открываются новые функциональные островные зоны, но стартовые не обесцениваются.

### Типы объектов

- функциональные здания;
- story landmarks;
- косметические здания;
- трофеи;
- питомцы/существа;
- растения;
- свет/погода/окружение;
- сезонные объекты;
- редкие «легендарные» экспонаты.

## 5. Progression axes

Игрок одновременно прогрессирует в нескольких направлениях:

1. **Story Progress** — главы и открытия.
2. **Island Restoration** — зоны и здания.
3. **Explorer Level** — общий уровень аккаунта.
4. **Collection Score** — найденные предметы и редкости.
5. **77 Bond/Repair** — восстановление и персонализация робота.
6. **Expedition Capability** — дальность/слоты/эффективность экспедиций.
7. **Season Progress** — временная дорожка.
8. **World Network** — открытые планеты и узлы.

Не все системы должны быть доступны с первого дня.

## 6. Unlock cadence

Нельзя показывать игроку 12 систем в первые 10 минут.

Предлагаемая последовательность:

### Первые 10 минут

- core puzzle;
- ресурсы;
- расчистка/восстановление;
- робот 77;
- первая визуальная кастомизация.

### День 1

- задания;
- первая мини-коллекция;
- простая экспедиция;
- первая странная находка.

### День 2–3

- маяк/радио;
- события;
- друзья/визиты опционально;
- первая редкая находка.

### День 4–7

- первая большая mystery-цепочка;
- доступ в пещеры;
- подземная дверь.

### Неделя 2+

- исследовательская база;
- полноценная сюжетная глава;
- длинные экспедиции;
- компоненты корабля.

### Поздняя early game / midgame

- корабль;
- запуск;
- карта миров.

Точная длительность до космоса определяется телеметрией. Нельзя искусственно растягивать reveal только ради monetization.

## 7. Resource model

### Soft currencies/resources

- Supplies — общий ресурс восстановления.
- Parts — техника/ремонт.
- Research Data — научные открытия.
- Bio Samples — отдельные планеты/экспедиции.

Количество ресурсов нужно держать минимальным. На старте игрок не должен видеть больше 2–3 одновременно.

### Premium currency

Рабочее имя: **Crystals**.

Используется для:

- косметики;
- мгновенного завершения некоторых таймеров;
- дополнительных попыток/boosters;
- отдельных convenience-действий.

### Lore resource

**Echo / Эхо** — редкая сюжетная субстанция/энергия древней сети.

Она не должна быть обычной премиум-валютой. Игрок не должен иметь возможность просто купить 5000 Echo и пропустить смысл открытия.

## 8. Fail states

Core puzzle может иметь поражение, но metagame не должен уничтожать имущество, ресурсы или многодневный прогресс.

Поражение должно говорить: «попробуй иначе», а не «ты потерял всё».

## 9. Difficulty philosophy

- первые уровни дают ощущение умения, а не экзамена;
- сложность растёт через новые комбинации правил, а не только числа;
- сложные пики чередуются с лёгкими уровнями;
- boosters помогают, но уровень не проектируется так, чтобы booster был фактически обязательным;
- невозможные/раздражающие уровни должны обнаруживаться аналитикой и автоматически попадать в review queue.

## 10. No-combat default

На ранних версиях нет классического боя. Опасность реализуется через:

- puzzle constraints;
- environmental hazards;
- экспедиционные риски;
- narrative tension.

Если позже появятся существа/антагонисты, конфликт не обязан превращать игру в RPG combat.

## 11. Sessions and offline friendliness

Игрок должен иметь возможность:

- пройти базовые puzzle levels без постоянного realtime multiplayer;
- продолжить часть прогресса при нестабильной сети;
- синхронизироваться при восстановлении связи.

Покупки, социальные действия, cloud save и LiveOps требуют сети.

## 12. Ethical design rules

Запрещено как базовая стратегия:

- продавать сюжетный финал;
- маскировать реальные цены;
- использовать forced ads после каждого уровня;
- создавать pay-to-win PvP;
- делать ключевые предметы только из random loot box;
- искусственно ломать уровень после серии побед ради покупки booster;
- использовать misleading countdown, который «обнуляется» и возвращается.

## 13. Definition of fun

Project 77 должен приносить удовольствие тремя независимыми способами:

1. «Я решил задачу».
2. «Я сделал свой мир лучше».
3. «Я узнал/нашёл что-то новое».

Если остаётся только один из трёх, продукт теряет устойчивость.
