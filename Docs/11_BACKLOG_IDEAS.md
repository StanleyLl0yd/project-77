# Project 77 — Idea Backlog

Этот файл содержит идеи, которые **не считаются обещанными функциями**. Они не входят в GDD автоматически.

## Priority legend

- P0 — candidate for core product.
- P1 — strong post-MVP idea.
- P2 — interesting experiment.
- Icebox — сохранить, но не планировать.

## Narrative

### P1 — 77 memory fragments

Игрок собирает повреждённые memory shards; некоторые дают ложный/неполный контекст до позднего reveal.

### P1 — Island changes by night

Редкие объекты/сигналы появляются только в разных ambient states, без необходимости играть ночью по реальному времени.

### P1 — Hidden coordinate chains

Коллекционные предметы складываются в координату будущего события.

### P2 — Unreliable logbook

Два журнала предыдущей экспедиции противоречат друг другу.

### Icebox — The island itself is a node

Поздний reveal: остров выбран не случайно; геология/структура связана с сетью.

## Social

### P1 — Postcard from another island

Игрок может отправить другу красиво сформированную postcard snapshot.

### P1 — Cooperative restoration monument

Сезонное глобальное строительство на всех островах.

### P2 — Guest 77 hologram

Роботы друзей временно появляются как голограммы на острове.

## Collecting

### P0/P1 — Museum / Archive

Физическое здание на острове, где видны найденные коллекции.

### P1 — Living collections

Некоторые существа не просто карточки, а появляются в мире.

### P2 — Set bonuses are cosmetic

Полная коллекция меняет ambient effect, а не даёт power.

## LiveOps

### P1 — Global cipher

Разные игроки получают разные части encrypted transmission.

### P1 — Anniversary island scar

Каждый год оставляет постоянный визуальный объект на старых островах.

### P2 — Weather anomaly week

Сезонная погода меняет island visuals и puzzle skin.

## Core gameplay

### P1 — Boss puzzle without combat

Большая многоэтапная схема/система вместо boss fight.

### P2 — Daily handcrafted puzzle

Один общий уровень для всех игроков с comparison stats.

### P2 — Community route puzzle

Каждый игрок активирует маленький участок гигантской сети.

## Meta

### P1 — Ship cabin customization

После открытия корабля появляется небольшое персональное пространство.

### P1 — Research board

Игрок визуально соединяет найденные clues; часть связей автоматическая, чтобы не превращать игру в detective spreadsheet.

### P2 — Photo mode

Снимки острова/планет для sharing.

## Monetization

### P1 — Cosmetic bundles themed by discovered planet

Покупка после возвращения домой, а не popup на поверхности новой планеты.

### P2 — Supporter Pack

Прямой набор для игроков, которые хотят поддержать игру, с vanity badge и cosmetics, без gameplay advantage.

## Future gameplay

### Icebox — Light asynchronous crews

Небольшие группы игроков для общих milestones, без realtime MMO.

### Icebox — User-created decorative island presets

Только если появятся moderation/tooling resources.

### Icebox — PC version

Рассматривать после mobile product-market fit, а не как launch dependency.
